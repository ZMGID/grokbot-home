# 机械结构说明 (mechanical)

源文件: `params.py`(唯一尺寸来源，PCB 生成脚本也引用它) + `cad.py`(CadQuery) + `render.py`(渲染/尺寸图)。
重新生成: `pip install cadquery trimesh matplotlib && python3 cad.py && python3 render.py`

## 关键尺寸
- 外形约 95 × 94 × 30 mm（含旋钮 ≈ 40 mm），超椭圆轮廓 + 四边内凹腰线(params.WAIST)，顶面 R300 球面拱顶(顶点偏后 20 mm，前低后高)，上沿 R7 枕形过渡，底边 R3，壁厚 2.2 mm。
- 键帽顶面高出局部拱面 2.2 mm，顶面带 R40 浅凹指窝；法兰在壳内皮下 0.4 mm 作为行程止挡。
- 分模面 z = 8 mm；下壳 1.5 mm 高止口(单边 0.15 mm 间隙)插入上壳。
- PCB：外壳轮廓向内偏移 3.2 mm（与外壳同源 outline_pts），, 1.6 mm，底面位于 z = 13 mm，被上壳螺柱(压)和下壳螺柱(托)夹紧。
- 4 × M2×14 DIN912 内六角从下壳底部沉孔(Ø4.4×2.4, 通孔 Ø2.4) → PCB 孔(Ø2.2) → 上壳螺柱内 M2×4×OD3.5 热熔铜螺母(孔 Ø3.2×5, 螺柱 Ø6.6)。
- FDM 打印细节、方向、支撑见 ../docs/3D打印说明.md 与 ../print/；按键为 6×6×5.5 轻触(TS-1102S)，带导向套；USB 外侧沉台 13×7.5 剩 0.8 mm 壁；拨动开关槽 + 指槽 + 延长块；滚轮支架与上壳一体(U 形槽, Ø3×14 销)。
  位置 (-40,24) (-38,-34) (42,12) (28,-12)。上壳螺柱已裁切到内腔面，不会顶穿拱顶。
- 按键帽与壳孔单边间隙 0.25 mm（FDM 建议 0.3，注塑 0.10–0.15）；帽高出壳面 1.2 mm；
  帽柱底面与轻触开关(TS-1187A, 1.5 mm 高)之间预留 0.3 mm 空行程。
- USB-C 开口 10.0 × 4.0 mm 位于后壁中央；电源拨动开关槽 8 × 3 mm 位于后壁 x = 33。
- 电池仓 50.6 × 34.6 mm（603450 1000 mAh LiPo），围框高 3 mm。

## 3D 打印建议
- 光敏树脂(JLC3DP 9000R/8228)外观最好；FDM 用 0.2 mm 层高、PETG，上壳顶面朝下打印需支撑。
- 打印件的自攻底孔可能需要用 1.6 mm 钻头修孔；或改用热熔铜螺母(M2 OD3.2)，把 `cad.py` 中 pilot 改为 Ø3.2。

## 注塑量产注意 (需模具厂 DFM 评审)
- 当前模型 **未加拔模角**：外观面需 1–2°、内部筋/柱 0.5–1° 拔模；纹理面按咬花深度加大拔模。
- 螺柱根部壁厚偏厚(实心 Ø6.4)，量产建议改为 Ø5.5 外径 + 加强筋，并在柱根做掏胶，防缩痕。
- 按键帽建议改为 "整片硅胶/硬胶二次成型" 或带悬臂弹片的一体按键，减少零件数。
- 上壳顶面按键孔间距最小处约 3 mm，模具强度 OK；侧壁 USB/开关槽需要滑块(或改为下壳开槽)。
- 推荐 PC/ABS (如 Covestro Bayblend) 或 ABS + 喷涂/IMD 实现粉色哑光外观。

渲染: `python3 render_final.py`（raster.py 为纯 numpy 软件光栅器，无需 GPU）。

布尔运算使用模糊容差 + ShapeFix (fcut/funion)，因为样条轮廓与球面求交易产生公差问题；所有导出零件均通过 isValid 检查。
