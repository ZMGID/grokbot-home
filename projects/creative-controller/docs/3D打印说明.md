# 3D 打印说明（FDM，0.4 mm 喷嘴，PETG / PLA）

所有打印文件位于仓库根目录 `print/`，**已按推荐方向摆放在打印床上（Z=0 即床面）**，直接导入切片软件即可，无需旋转。
源码：`mechanical/print_export.py`（由 `mechanical/cad.py` 生成的零件重新定向、修复网格、做悬垂检查、生成 3MF）。

| 文件 | 说明 |
|---|---|
| `plate0_tolerance_test.3mf` | 公差测试拼版（**第一个打印**） |
| `plate1_shells.3mf` | 上壳 + 下壳（如果 220×220 床放不下两件，请分两次打印） |
| `plate2_controls.3mf` | 7 个键帽、旋钮、装饰环、滚轮、导光柱、拨杆延长块、销轴 |
| `*.stl` | 每个零件单独的 STL（同方向） |
| `overhang_report.json` | 悬垂/桥接面积自检结果 |

## 1. 材料与通用参数
- **推荐 PETG**（韧、耐 70 °C、热熔螺母压入后不易开裂）；PLA 可用于打样，但夏季车内/阳光下会变形。
- 导光柱：透明/半透明 PETG（`light_pipe_clearPETG.stl`）。
- 喷嘴 0.4 mm；线宽 0.42–0.45 mm。
- 层高：外壳 0.2 mm（想要更顺滑的穹顶可用 0.16 mm 或可变层高）；键帽/旋钮/滚轮 0.12–0.16 mm。
- 墙：3 圈（≈1.3 mm），设计壁厚 2.2 mm，所以壳体侧壁基本为实心；顶/底层各 5 层。
- 填充：外壳 20% 螺旋/gyroid；键帽、旋钮、滚轮、延长块、销轴 100%（或 6 圈墙）。
- 温度（参考）：PETG 235–245 °C / 床 75–85 °C；PLA 205–215 °C / 床 60 °C。
- 首层：外壳底部外缘有 1.6 mm 45° 倒角，可消除象脚；**不要开边缘 brim 覆盖倒角**（会糊住），必要时用 3 mm brim 只在下壳。

## 2. 各零件摆放与支撑
| 零件 | 摆放方向 | 支撑 | 0.2 mm 层高估算时间 | 耗材(PETG) |
|---|---|---|---|---|
| top_shell 上壳 | 开口朝下、穹顶朝上 | **需要**：内部穹顶天花板、键帽导向套、螺柱、滚轮支架下表面需支撑；用"树状/有机支撑"，悬垂阈值 44°，**外表面无需支撑**（全部 <45°） | ≈ 4 h 53 min | ≈ 15.3 m / 47 g |
| bottom_shell 下壳 | 外底面贴床 | 可不加或"仅从打印床"支撑；沉头孔与脚垫凹槽为短桥接（≤10 mm），外缘倒角 42–45° | ≈ 2 h 22 min | ≈ 8.4 m / 26 g |
| 7 个键帽 | 顶面朝上（直立），法兰贴床 | 无（法兰 45° 倒角 + 45° 锥形过渡到柱） | 共 ≈ 1 h 05 min | ≈ 3.3 m / 10 g |
| knob 旋钮 | 顶面朝上 | 无；D 孔顶部为 Ø6 短桥接 | ≈ 28 min | ≈ 1.7 m / 5 g |
| knob_ring 装饰环 | 平放 | 无 | ≈ 3 min | 0.6 g |
| scroll_wheel 滚轮 | 侧面平放（轴线竖直） | 无；方轴孔/销孔竖直打印，尺寸最准 | ≈ 14 min | ≈ 2.4 g |
| light_pipe 导光柱 | 法兰朝下 | 无 | ≈ 3 min | 0.2 g |
| pwr_slider_ext 拨杆延长块 | 套孔朝下 | 无（1.5 mm 短桥接） | ≈ 1 min | <0.1 g |
| wheel_pin_optional 销轴 Ø3×14 | 竖直 | 无（建议直接用 Ø3×14 钢销/不锈钢定位销代替） | ≈ 1 min | <0.1 g |
| 公差测试件(板 + 销) | 平放 | 无 | ≈ 1 h 44 min | ≈ 14 g |

整机一套（不含测试件）约 **8.5 小时、≈ 90 g PETG**。时间/耗材为 PrusaSlicer CLI（0.2 mm、3 圈墙、20% 填充、壳体加支撑）估算，换机器/配置会有 ±30% 偏差。
自检（`overhang_report.json`）：除上壳内腔外，所有零件"比 45° 更平的朝下斜面"面积为 0（允许 2° 网格误差），水平朝下面只有短桥接。

## 3. 关键配合尺寸（FDM 补偿已含在模型内）
| 位置 | 设计值 |
|---|---|
| 键帽与壳孔、导向套 | 单边间隙 0.25 mm；导向套长 1.5 mm 保证键帽不歪 |
| 旋钮 D 孔 | Ø6.2 / 平面距 4.7（EC11 D 轴 Ø6 / 4.5），入口 0.5 mm 倒角 + 开口弹性槽，压入即紧 |
| 滚轮 | 方孔 1.95 mm（鼠标编码器 2.0 mm 方轴，微过盈），销孔 Ø2.95×5.5（Ø3 销压入）；滚轮与壳槽间隙 ≥0.6 mm |
| 滚轮支架 U 形槽 | 宽 3.3 mm（Ø3 销 + 0.3），顶部为 teardrop 顶，0.9 mm 下压行程触发 SW9 |
| 水平孔 | 全部为 teardrop（水滴）形或 45° 屋顶，无需支撑 |
| 热熔螺母孔 | Ø3.2 × 深 5 mm，入口 0.4 mm 倒角，螺柱外径 6.6 mm |
| USB-C 开口 | 9.8×4.0 通孔 + 外侧 13×7.5 mm 沉台（剩 0.8 mm 壁） |
| 拨动开关 | 6.5×3.6 槽 + 11×6 指槽 + 拨杆延长块 |

**先打公差测试件**：测试板上有 0.15/0.20/0.25/0.30 mm 间隙孔+配套销、D 轴孔、Ø3.0–3.3 热熔孔、teardrop 水平孔、2.0/2.05/2.1 方孔。
找出"能顺滑滑动但不晃"的间隙，若不是 0.25，修改 `mechanical/params.py` 中 `FDM_CLR`，然后运行
`cd mechanical && python3 cad.py && python3 print_export.py` 重新生成全部 STL/3MF。

## 4. 后处理
1. 拆支撑（上壳内腔），用斜口钳/刮刀清理导向套内壁和螺柱顶端，不要扩大导向套内径。
2. 键帽导向面、滚轮侧面可用 400–800 目砂纸轻磨；外壳可用 240→600 目砂纸 + 喷底漆/哑光漆，或热风枪极短时间扫一下去拉丝（PETG）。
3. 用 Ø3.2 钻头手转修一下热熔孔（只修毛刺），用 Ø2.4 钻头修下壳通孔。
4. 检查所有键帽能在孔中自由落下且不晃。

## 5. 热熔螺母安装
- 规格：**M2 × L4 × OD3.5 黄铜滚花热熔螺母**（4 个，淘宝/1688 "M2×4×3.5 热熔铜螺母"）。M3 版本不适用（螺柱太细）。
- 螺丝：**M2×14 DIN912 内六角**（4 颗，从下壳底部沉孔 Ø4.4×2.4 进入）。
- 方法：烙铁装热熔头（或普通尖头），PETG 230 °C / PLA 200 °C；螺母放在孔口，垂直轻压 3–5 s 至与螺柱顶面平齐或低 0.1 mm，立即用平面金属块压平 5 s 冷却定型。
- 不要过热、过压，否则塑料会从孔底挤出或螺母歪斜；歪了趁热用 M2 螺丝拧入校正。

## 6. 装配顺序
1. 打印公差件 → 校准 `FDM_CLR` → 打印全部零件。
2. 上壳压入 4 个热熔螺母。
3. 上壳倒扣：7 个键帽从内侧插入导向套；导光柱从内侧插入 LED 孔（可点一滴 UV 胶）。
4. 滚轮：Ø3 销压入滚轮销孔（或钢销），方孔套到 PCB 上 ENC2 编码器方轴。
5. PCB 预装拨杆延长块到 SW12；将 PCB 连滚轮一起放入上壳：USB/开关舌片对准后壁、销轴端落入滚轮支架 U 形槽、EC11 轴穿过旋钮孔。
6. 插电池线 J2，电池用双面胶粘在下壳电池仓。
7. 合下壳，4 颗 M2×14 拧入（≤0.2 N·m，不要拧死）。
8. 压入旋钮、装饰环，贴 4 个 Ø10×0.8 mm 硅胶脚垫。
9. 按 README 第 8 节测试：每个键帽按下有清脆触感、松开回弹不卡；滚轮转动顺滑、下压能触发；USB 线插到底。

## 7. 已知限制
- 打印时间/耗材是切片估算，未实际打印；配合尺寸需以公差测试件为准。
- 上壳需要内部支撑（不可见），支撑接触面会粗糙，但不影响装配面。
- 下壳 STL 有个别网格边不闭合（切片软件会自动修复）。
- 滚轮"以编码器轴为支点"的下压方式需实测编码器寿命。
