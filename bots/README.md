# bots/

每个 bot 一个文件夹：

- `profile.md`：名字、头衔、description（CreateAgent 用）、头像形状/颜色、设置
- `CONTEXT.md`：这个 bot 自己的记忆和项目状态（新 bot 建好后第一件事就是读它）
- `routines.md`：它的定时任务（或 none）
